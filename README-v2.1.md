# 兴宜街道红旗路输入法切换工具

一个轻量级的 Windows 输入法快速切换工具，使用全局快捷键（Win+J/K）在中英文输入法之间快速切换。

## ✨ 核心特性

- 🎯 **全局快捷键**: Win+J 切换英文,Win+K 切换中文
- 🖥️ **系统托盘运行**: 支持后台运行,无需保持终端窗口
- 🔒 **全局单例**: 确保只运行一个实例,避免资源浪费
- 🚫 **阻止系统快捷键冲突**: 完全拦截 Win+J/K,不触发系统原有功能
- 🔧 **底层键盘钩子**: 使用 Windows Low-Level Keyboard Hook API
- 💪 **稳定可靠**: 异步切换 + 互斥锁,防止并发问题
- 🎨 **友好界面**: 托盘图标 + 右键菜单,操作便捷
- 📦 **便携部署**: 只需两个文件,放在同一目录即可运行

## 📦 快速开始

### 1. 准备文件

将以下两个文件放在同一目录:

```
your-folder/
├── switch-input-method.exe    # 主程序
└── im-select.exe              # 输入法切换工具
```

### 2. 运行程序

双击 `switch-input-method.exe` 即可，程序会自动:
- ✅ 在系统托盘显示图标
- ✅ 开始监听快捷键
- ✅ 检测单例防止重复启动

### 3. 使用快捷键

| 快捷键  | 功能                    |
| ------- | ----------------------- |
| Win + J | 切换到英文输入法 (1033) |
| Win + K | 切换到中文输入法 (2052) |

### 4. 退出程序

右键点击系统托盘图标，选择"退出"

## 🎯 开机自启动 (可选)

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 将 `switch-input-method.exe` 的快捷方式复制到该文件夹
3. 重启电脑，程序会自动在后台运行

## 💡 使用场景

### 场景1: Vim/NeoVim 用户

在编辑器中快速切换输入法，避免模式切换时输入法干扰。

### 场景2: 多语言工作者

频繁在中英文之间切换，Win+J/K 比传统 Ctrl+Space 更顺手。

### 场景3: 键盘党

全程不需要离开键盘，不需要鼠标点击输入法切换。

这会编译出不显示控制台窗口的版本，适合日常使用。

## 🐛 故障排除

### 问题1: 提示"程序已在运行中"

**原因**: 已有一个实例在运行

**解决**:
1. 检查系统托盘图标
2. 如需重启，右键托盘图标退出
3. 然后重新启动

### 问题2: 提示"切换输入法失败"

**原因**: 找不到 im-select.exe

**解决**:
1. 确认 `im-select.exe` 与 `switch-input-method.exe` 在同一目录
2. 检查文件权限
3. 尝试以管理员身份运行

### 问题3: 快捷键不生效

**原因**: 可能被其他程序占用或需要管理员权限

**解决**:
1. 确认程序正在运行 (查看托盘图标)
2. 检查是否有其他软件占用 Win+J/K
3. 尝试以管理员身份运行程序

### 问题4: 找不到托盘图标

**原因**: 托盘图标可能被隐藏

**解决**:
1. 点击任务栏右下角的 `^` 展开隐藏图标
2. 设置 → 个性化 → 任务栏 → 选择显示的图标

## 📚 技术架构

```
main.go
  ├─ ensureSingleInstance()     # 全局单例检查
  ├─ StartKeyboardHook()        # 键盘钩子 (goroutine)
  │    └─ 监听 Win+J/K
  │    └─ 调用 switchInputIfNeeded()
  ├─ InitTray()                  # 托盘界面 (主线程)
  │    ├─ 显示托盘图标
  │    ├─ 创建右键菜单
  │    └─ 处理退出事件
  └─ getIMSelectPath()           # 智能路径查找
       └─ 查找同目录的 im-select.exe
```
